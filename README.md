## 🤖 Featured Robotics Projects

### 🏭 [ROS 2 Warehouse Autonomous Navigation](https://github.com/Sara-Esm/ros2-warehouse-autonomous-navigation)
> TurtleBot3 executes a 5-step autonomous warehouse mission — navigating to 4 stations and returning home, with ArUco marker verification at each stop.

- **Stack:** ROS 2 Humble · Nav2 · AMCL · Cartographer SLAM · OpenCV · Gazebo 11
- **Result:** 5/5 mission steps completed · 0 failures · 100% ArUco verification rate
- **Highlights:** NavigateToPose action client · SLAM-built map · timed launch sequence

---

### 👁️ [TurtleBot3 Semi-Autonomous Visual Servoing with SMC](https://github.com/Sara-Esm/turtlebot3_color_follower)
> Human drives robot freely; when a colored fiducial marker is detected, SMC autonomously aligns, approaches, and stops in front of the target.

- **Stack:** ROS 2 Humble · OpenCV · Sliding Mode Control · Gazebo 11
- **Highlights:** Velocity mux (teleop override) · two-stage false-positive rejection · active braking
- **Control law:** `u = -k_s · tanh(s/φ) - k_eq · e` with chattering suppression
